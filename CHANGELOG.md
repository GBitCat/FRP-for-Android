## [Unreleased]

### Added
- Initial project setup
- Basic Android project structure with Kotlin and Jetpack Compose
- FRP configuration management using Room database
- FrpManager class for managing frpc process
- FrpService foreground service for background operation
- Main UI with configuration list and status display
- ConfigEditActivity for adding/editing configurations
- LogActivity for viewing frpc logs
- SettingsActivity for app settings
- BootReceiver for auto-start on boot
- Hilt dependency injection setup
- Build scripts for downloading frpc, building, testing, and deploying
- Unit tests and Android instrumented tests
- README, LICENSE, and documentation files
